# 그림 기반 플레이 목업

`PlayPrototype.bat`를 더블클릭한다. 기존 군수 코어에 그림 레이어·로컬 AI·총기 상태·화면 효과를 연결한 검증용 장면이다.
아직 에셋이 없어도 시작 시 만든 임시 그래픽과 HUD로 실행된다.
기본 맵은 **448×320m 소형 지역**이다. M으로 지도를 열어 안전가옥·물류창고·HQ·통신시설과 도로를 확인한다.

```powershell
py -3.13 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r prototype/requirements.txt
& .\.venv\Scripts\python.exe -B -X utf8 -m prototype
```

현재 프로젝트 가상환경에 Pico2D가 준비되어 있다. 가상환경은 Git에 포함하지 않는다.
에셋 규격은 [assets/prototype/README.md](../assets/prototype/README.md)를 따른다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / Shift / Ctrl | 기본 이동 3m/s / 달리기 5m/s / 조용한 걷기 1.5m/s |
| 마우스 / 우클릭 유지 | 조준 방향 / 정밀 조준 |
| 좌클릭 | 발사. 재장전 중 새로 누르면 현재 단계를 취소하고 약실 탄환이 있을 때 발사 |
| V | 단발·연사 전환 |
| R | 재장전 시작·중단된 단계부터 재개 |
| C | 재장전 취소 |
| 1 / 2 | 총기 교체. 이전 총기의 완료된 재장전 단계 보존 |
| 휠·`+`·`-` | 검증용 50~400% 줌 |
| F / E | 가까운 문 사용 / 보급품·바닥 무기·안전가옥 예비 키트 사용 |
| Enter | 전투 불능 상태에서 6게임시간 진행 후 무장 없이 안전가옥으로 복귀 |
| P / F1 / Esc | 시간 정지·재개 / 판정 정보 / 종료 |
| M | 지역 지도. 지도에서도 세계 시간 진행 |

포커스를 잃으면 일시정지하며 P로 재개한다. 일시정지는 재장전 취소가 아니므로 단계 내부 시간도 멈춘다.
초기 총기는 장전되어 있다. 먼저 한 발 발사한 뒤 R을 누르면 재장전을 확인하기 쉽다.

## 적군 AI 검증

루트의 `PlayAITest.bat`를 실행하면 기존 물류창고의 발소리 장면이 정지 상태로 열린다.
P로 시작하고, F2로 현재 장면을 초기 상태에서 다시 시작하거나 F3으로 다음 장면을 선택한다.
F1은 가까운 병사 4명의 단서·행동·경로 상태와 이동 경로 표시를 켜거나 끈다.

| 장면 | 재현 방법 |
| --- | --- |
| 발소리 조사 | 닫힌 문 안쪽에서 Ctrl 걷기와 일반 이동을 비교한다. |
| 목격 후 수색 | 호위에게 발견된 뒤 열린 문으로 들어가 옆으로 이동한다. |
| 무전 사용 / 차단 | 시작 위치에서 발사하지 않고 기다린다. 정면 호위의 발견에 창고 반대편 호위가 어떻게 반응하는지 비교한다. |

추격 인계는 무전 사용 장면에서 보고가 전달된 뒤 확인한다. F1에서 추격 담당을 확인하고, 그 병사를 제압하거나 쓰러뜨린 뒤 다른 병사에게 추격이 넘어가는지 본다.

원하는 장면으로 바로 시작하려면 `PlayPrototype.bat --ai-scenario search`를 실행한다.
선택값은 `sound`, `search`, `radio`, `radio-off`다.

## 단계식 재장전

총기 정의는 `data/weapons.json`, 진행 상태는 `weapons.py`의 `WeaponState`에 있다.

| 총기 | 탄창 | 탄창 빼기 | 탄창 끼우기 | 볼트캐치 | 합계 |
| --- | ---: | ---: | ---: | ---: | ---: |
| AR-01 | 30+1 | 0.5초 | 1.0초 | 0.5초 | 2.0초 |
| AR-02 | 20+1 | 0.65초 | 1.25초 | 0.7초 | 2.6초 |

AR-02는 단계 시간 차이를 확인하기 위한 임시 총기 데이터다. 수치 전체가 최종 밸런스는 아니다.

- 완료된 단계와 그 물리적 결과만 보존한다. 취소한 단계의 내부 진행 시간은 0으로 초기화한다.
- 예: AR-01의 탄창 빼기 완료 후, 끼우기를 0.4초 진행하다 취소하면 R 재개에 **1.5초**가 걸린다.
- 탄창 빼기 완료 시 분리된 탄창의 잔탄은 예비 탄약 풀로 옮긴다. 개별 탄창 아이템은 아직 구분하지 않는다.
- 끼우기 완료 시 예비 탄약에서 새 탄창으로 옮긴다. 볼트캐치 완료 시 빈 약실에 한 발을 공급한다.
- 약실에 남은 탄환은 탄창 제거와 별개다. 재장전을 취소하면 약실 탄환을 발사할 수 있다.
- 재장전 중 이동 속도는 총기별 `reload_move_multiplier`를 적용한다.
- 무기 교체·바닥에 떨어뜨리기·회수에서도 같은 총기 상태 객체를 유지한다. 실행 종료 후 저장·복원은 후속 범위다.

## 화면·교전·AI

- 화면 방향은 고정하며 몸통·별도 무기는 몸통 중심의 조준 방향으로 회전한다. 무기 장착점·그립·총구·실제 크기는 총기 데이터에 있다.
- 몸통 원본은 위쪽 바라보기 기준이며 어깨 폭 0.75m·앞뒤 두께 0.375m다. 무기의 오른쪽 바라보기 기준과 회전 보정을 분리한다.
- 확대율은 물리·사거리·판정 크기를 바꾸지 않는다. 표시 크기와 몸체 충돌은 독립이다.
- 플레이어 고정형 카메라에 최대 2m의 마우스 방향 오프셋을 적용한다.
- 발사·피격·재장전 단계마다 렌더링 전용 흔들림을 적용한다. 조준·탄도 좌표에는 적용하지 않는다.
- 주변 적의 경계·수색·교전 수준에 따라 빨간 비네팅 알파가 완만하게 바뀐다.
- 일반 총기는 PRD 기준 히트스캔이다. 가장 가까운 충돌부터 처리하며 AR은 인간 또는 얇은 목재/석고 1개까지 관통한다.
- 몸통에서 총구까지 벽에 막힌 발사는 탄약을 소비하고 해당 벽에서 멈춘다.
- 거리·시야각·벽 차폐로 관측한다. 약한 소리에는 방향을 살피고, 의심도가 쌓이면 소리가 난 구역으로 이동해 주변을 확인한다.
- 지역 경비는 초기 16명이다. HQ 10명 중 2명은 도로 순찰, 통신시설 2명, 창고 수송 호위 4명으로 배치한다.
- 주둔군·순찰조·수송 호위에 같은 전술 AI를 적용한다. 시야를 잃으면 마지막 목격 위치와 방향을 사용하며, 조사 지점이 막혔으면 갈 수 있는 주변 지점을 찾는다.
- 피격과 가까이 지난 탄도가 제압도를 올린다. 적은 교전 중 사격·접근·측면 이동·엄폐·후퇴를 상황에 따라 선택하고 잠시 유지한다.
- 직접 목격한 적은 가까운 동료에게 알리거나 지역 통신시설을 통해 대략적인 구역을 전달한다. 추격 담당이 제압되거나 쓰러지면 대응 가능한 병사가 이어받는다.
- 같은 보고에 반응한 병력은 확인한 수색 지점을 공유한다. 차단 담당은 예상 도주 방향의 출입구를 우선하고, 길이 막히면 다음 후보로 이동한다.
- 경비의 실제 캠페인 부대 ID와 멤버 ID를 유지한다. 사망은 해당 부대에서 한 번만 차감하고 지역 재접근·복귀로 초기화하지 않는다.
- 수송 호위는 집결 지점으로 이동하고 실제 출발 후에는 차량 탑승 인원으로 처리한다. 교전 중이거나 집결이 끝나지 않으면 출발을 기다린다.
- AI는 접근 경로상의 사용 가능한 문을 연다. 문 데이터의 `ai_access`로 권한을 조정할 수 있다.
- HP·Armor·탄약·재장전은 적에게도 적용된다. 플레이어가 전투 불능이면 실제 군수 시간을 6시간 진행한 뒤 무장 없이 복귀한다.
- 바닥 무기에는 남은 탄약과 완료된 재장전 단계가 보존된다. 안전가옥의 예비 키트는 장면당 한 번 사용할 수 있다.

**벽 뒤 적을 화면에서 숨기는 기능은 보류**했다. AI 자체의 시야 차폐와 탄환 충돌은 작동한다.
오디오는 재생하지 않는다. 총성·재장전·문·발걸음은 `events.py`의 논리 이벤트로 전달되므로 이후 음향을 구독 방식으로 연결할 수 있다.

## 장면·모듈

기본 `scenarios/rear_region.json`은 448×320m 필드이며 기존 80×56m 장면보다 면적이 32배다.
안전가옥·창고·HQ·통신시설과 우회 도로, 군집 수목 320개를 배치했다.
그림 위의 내비게이션 노드·희소 연결과 충돌 영역은 미터 단위 데이터이며 타일맵을 생성하지 않는다.

90도 회전 프리팹의 그림·벽·문·노드를 함께 변환한다. 안전가옥에서 HQ까지 검증용 이동 경로는 360m다.
기존 80×56m 장면은 `--scene prototype/scenarios/image_yard.json`으로 선택한다.
시설 형태는 `data/facility_prefabs.json`, 배치 조립은 `prefabs.py`·`region.py`,
정적 범위 조회는 `spatial.py`에서 관리한다.
지역 그림은 화면 주변 항목만 조회하고, `map_images.py`의 최대 24항목 LRU에 보관한다.
이미지 생성·로드는 프레임당 최대 두 항목으로 제한하고 같은 재질·변형은 공유한다.
시설 내부 소품과 수목은 시작 시 만든 작은 공용 그림을 사용한다.
60m 밖 경비는 시야·전투 판단을 생략하고 0.5초 간격의 순찰 갱신을 사용한다.
M 지도에는 도로·시설·플레이어를 표시하며 전체 적 위치는 F1 개발 정보에서만 표시한다.

## 지역에서 할 수 있는 것

- 안전가옥의 초록 단말에서 무장 없는 상태로 예비 키트를 한 번 확보한다.
- 창고의 노란 단말에서 E로 실제 캠페인 보급품을 10개씩 확보한다.
- HQ·통신시설 단말에서 E로 피해를 25%씩 누적해 기능을 무력화한다. 실제 군수 시설 상태와 진행 중 수송에 반영한다.
- 실제 군수 도로와 같은 좌표에서 보급·외부 출하 수송대가 이동한다. 수송대는 화면과 지도에 대표 차량으로 표시한다.
- 주둔 병력 일부가 호위로 출발하고 실제 귀환 후 다시 나타난다. 같은 인물을 별도 병력으로 중복 생성하지 않는다.
- 전투 불능 후 Enter로 6게임시간을 진행해 복귀한다. 이때 군수는 추상 상태로 계속 진행하고 사망·피해·탄약은 유지한다.

| 모듈 | 책임 |
| --- | --- |
| `world.py`, `geometry.py`, `navigation.py`, `movement.py` | 그림 배치·공간 해시·희소 경로·몸체 이동 |
| `actors.py`, `weapons.py`, `data/weapons.json` | 개체·총기 정의·약실/탄창·단계 재장전 |
| `combat.py`, `events.py` | 히트스캔·관통·피격·논리 이벤트 |
| `perception.py`, `ai.py`, `cover.py` | 지각/기억·의사결정·자동 엄폐 후보 |
| `feedback.py`, `camera.py` | 흔들림·경계 알파·좌표 변환 |
| `visual_assets.py`, `rendering.py`, `hud.py` | 시작 시 생성/로드한 그림·회전·HUD |
| `bridge.py`, `roster.py`, `interactions.py`, `simulation.py` | 캠페인 좌표·병력·수송·시설 기능과 로컬 플레이 연결 |
| `controls.py`, `__main__.py` | 입력·실행 루프 |

지역 장면의 병력과 시설 손실은 실제 캠페인 상태에 연결했다. 무기·탄약은 아직 로컬 장비 상태이며 캠페인 탄약 상자와의 환산·보급은 후속 범위다.
차량은 운송대·주차 거점의 대표 표시다. 상세 차량 충돌·승하차·차량 전투, HQ 보고·QRF 출동·해방·통합 저장은 후속 범위다.
기존 작은 장면의 경비는 훈련용 개체다. 예비 총기 키트도 검증용 배치다.

## 성능과 확인 범위

리소스·임시 그래픽·비네팅은 시작 때 한 번 준비한다. 발사 때 파일 I/O나 맵 텍스처 재생성을 하지 않는다.
HUD 글자는 캐시하고 내용은 초당 5회 갱신한다. 몸체와 회전된 무기 범위를 각각 화면 밖 제거에 사용한다.
벽은 ray가 지난 공간 해시 셀의 후보만 검사한다. AI 관측은 0.15초 간격으로 분산하고,
경로는 목적지·문 상태가 바뀌거나 병력이 다른 거점으로 이동했을 때 다시 계산한다. 경로 계획은 병사별 0.2초 간격과 틱당 한 명으로 제한한다.
표시용 탄적·이벤트 이력은 각각 최대 128개다.

이번 작업의 확인은 핵심 재장전 경계·탄약 보존·기초 교전/이벤트 연결·창 시작에 한정한다.
일반 플레이·밸런스·최악 장면 성능 확인은 사용자가 수행한다.

```powershell
py -3.13 -B -X utf8 -m prototype --headless --frames 180
& .\.venv\Scripts\python.exe -B -X utf8 -m prototype --frames 45
```
